## 4. 外部キー制約

### 4.1 参照整合性
- 受入実績 → 部品マスター (BuhinCode)
- 受入実績 → 取引先マスター (TorihikisakiCode)
- 払出実績 → 部品マスター (BuhinCode)
- 単価マスター → 部品マスター (BuhinCode)
- 単価マスター → 取引先マスター (TorihikisakiCode)
- 納入先マスター → 取引先マスター (TorihikisakiCode)

### 4.2 カスケード設定
- 削除: NO ACTION (論理削除使用)
- 更新: CASCADE (コード変更時の自動更新)

## 5. データ型設計

### 5.1 文字列型
- **コード系**: NVARCHAR(固定長) - 部品コード、取引先コード等
- **名称系**: NVARCHAR(可変長) - 名称、住所等
- **備考系**: NTEXT - 長文対応

### 5.2 数値型
- **数量**: DECIMAL(10,2) - 小数点以下2桁対応
- **金額**: DECIMAL(12,2) - 大きな金額対応
- **ID**: INT IDENTITY - 自動採番

### 5.3 日付型
- **日付**: DATE - 年月日のみ
- **日時**: DATETIME - 年月日時分秒
