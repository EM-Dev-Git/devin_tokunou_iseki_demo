## 2. アーキテクチャ詳細分析

### 2.1 レイヤー構成詳細

#### プレゼンテーション層 (IbUkeharai)
- **フォーム数**: 38個以上
- **主要フォーム**:
  - MainForm: メインメニュー
  - BaseMenuForm: メニューフォームの基底クラス
  - RegisterMenuForm: 登録メニュー
  - BatchMenuForm: バッチ処理メニュー
  - CreateDataMenuForm: データ作成メニュー

#### ビジネスロジック層
- **共通処理**: DitCoreライブラリ
- **データ処理**: 各フォーム内のビジネスロジック
- **設定管理**: XmlConfigControl

#### データアクセス層 (DitDataAccess)
- **データベース接続**: SqlDataBase クラス
- **スキーマ管理**: SchemaInfo/SchemaDetail
- **ファイル出力**: OutputLine クラス

### 2.2 データフロー分析
```
外部システム (FTP) → 受入データ → データベース → 処理 → 帳票出力
                                    ↓
                              払出データ → 外部システム (FTP)
```
