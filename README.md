# devin_tokunou_iseki_demo リポジトリ解析結果

## 概要
このリポジトリは、井関物流向けの受払管理システム（在庫管理システム）のVB.NETアプリケーションです。部品の受入・払出実績管理、マスターデータ管理、各種帳票出力機能を提供する業務システムです。

## システム構成

### アプリケーション構造
- **メインアプリケーション**: IbUkeharai
- **共通ライブラリ**: DitCore
- **データアクセス層**: DitDataAccess

### 技術仕様
- **開発言語**: VB.NET
- **フレームワーク**: .NET Framework 4.6
- **データベース**: SQL Server (UkeharaiDB_Matsuyama)
- **レポート**: Microsoft Reporting Services (RDLC)
- **外部連携**: FTP サーバー連携
- **Office連携**: Microsoft Excel COM参照

## 主要機能

### 1. 登録機能
- 受入実績登録
- 払出実績登録

- 部品マスターデータ作成
- 取引先マスターデータ作成
- 納入先マスターデータ作成

### 3. 帳票・リスト出力機能
- 受払報告書
- 受払確認表
- 部品別受払プリント
- 在庫受注残リスト
- 実績内訳表出力

### 4. 照会機能
- 受払実績照会
- 欠品部品情報照会

### 5. バッチ処理機能
- 受入データ書き込み
- 払出データ書き込み（ホスト連携）
- 月次データ処理
- 年次データ処理

## アーキテクチャ

### レイヤー構成
1. **プレゼンテーション層**: Windows Forms UI
2. **ビジネスロジック層**: IbUkeharaiメインアプリケーション
3. **共通機能層**: DitCore（共通コンポーネント、ダイアログ、設定管理）
4. **データアクセス層**: DitDataAccess（SQL Server接続、スキーマ管理）

### 主要コンポーネント

#### DitCore
- XmlConfigControl: 設定ファイル管理
- CclDateTimePicker: カスタム日付コントロール
- CclBuhinCode: 部品コードコントロール
- DlgProcess: プロセス実行ダイアログ
- OutputLog: ログ出力機能

#### DitDataAccess
- SqlDataBase: SQL Server接続管理
- SchemaInfo/SchemaDetail: データベーススキーマ管理
- ItemInfo: アイテム情報管理
- OutputLine: ファイル出力機能

## 設定ファイル
システムの動作設定は `Config.xml` で管理されており、以下の設定が含まれます：
- データベース接続情報
- FTPサーバー設定
- 拠点別ファイル名設定
- ログファイル設定
- メモリ使用設定

## 開発環境
- **Visual Studio**: 2017以降推奨
- **SQL Server**: Express Edition以降
- **レポートビューアー**: Microsoft ReportViewer 150.1537.0
- **Office**: Excel COM連携用
