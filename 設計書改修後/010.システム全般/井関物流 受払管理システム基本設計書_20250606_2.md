# 井関物流 受払管理システム基本設計書_20250606_2

## 1. システム概要

### 1.1 システム名称
井関物流 受払管理システム（IbUkeharai）

### 1.2 システム目的
井関物流における部品の受入・払出業務の効率化と請求処理の精度向上を目的とした業務管理システム

### 1.3 改修概要（2025年6月6日版）
本改修では、請求処理における人的ミス防止と業務効率化を目的とした以下の機能を追加実装する：

#### 基本改修要件（5項目）
1. **自動計算機能**: 単価×数量による金額自動計算
2. **入力促進機能**: 未入力項目の背景色変更による入力促進
3. **金額フィールド保護**: 金額の手入力禁止（グレーアウト）
4. **単位項目追加**: 請求書用の単位フィールド新設
5. **単位入力必須化**: 単位未入力時のエラー表示

#### 請求書フォーマット変更要件（新規追加）
6. **列分離表示**: 数量と単位を縦線で分離した表示形式
7. **RDLC修正**: OutputSeikyuReportS.rdlcの列構造変更
8. **列幅最適化**: 数量列3.0cm、単位列0.8cm設定

### 1.4 改修背景
**2025年3月発生事案を受けた再発防止対応**
- 熊本生産グループでの発送運賃請求内容入力漏れによる会計処理ミス
- 根本原因：請求マスタでの自動計算機能不備
- 対応方針：システム機能追加による人的ミス防止

## 2. システム機能要件

### 2.1 請求マスター登録機能（改修対象）

#### 2.1.1 自動計算機能
**機能概要**: 単価、数量入力後、金額が自動計算される機能

**詳細仕様**:
- 計算式: 金額 = 単価 × 数量
- 計算タイミング: 単価または数量フィールドの値変更時
- 小数点処理: 四捨五入（円単位）
- エラーハンドリング: 非数値入力時の適切な処理

**実装方式**:
```vb
Private Sub CalculateAmount()
    If IsNumeric(txtTanka.Text) AndAlso IsNumeric(txtSuryo.Text) Then
        txtKingaku.Text = (CDec(txtTanka.Text) * CDec(txtSuryo.Text)).ToString("N0")
    End If
End Sub
```

#### 2.1.2 入力促進機能
**機能概要**: 単価、数量いずれか未入力の場合、背景色変更による入力促進

**詳細仕様**:
- 対象フィールド: 単価、数量、単位
- 警告色: 薄い赤色（#FFE6E6）
- 検証タイミング: フィールド離脱時
- 正常色復帰: 適切な値入力完了時

#### 2.1.3 金額フィールド保護機能
**機能概要**: 金額フィールドの手入力禁止

**詳細仕様**:
- ReadOnly属性: True
- 背景色: グレー（#F0F0F0）
- フォーカス制御: Tab順序からスキップ
- 表示内容: 自動計算結果のみ

#### 2.1.4 単位項目追加機能
**機能概要**: 請求書記載用の単位フィールド追加

**詳細仕様**:
- フィールド名: TANI
- データ型: VARCHAR(10) NOT NULL
- 入力方式: コンボボックス
- 選択肢: 個、本、台、式、kg、m、㎡、その他
- 初期値: 'その他'

#### 2.1.5 単位入力必須化機能
**機能概要**: 単位フィールドの入力必須化

**詳細仕様**:
- 必須チェック: 保存時実行
- エラー表示: 背景色変更（#FFE6E6）
- エラーメッセージ: 「単位を入力してください」
- 必須マーク: ラベルに（*）表示

### 2.2 請求書出力機能（改修対象）

#### 2.2.1 請求書フォーマット変更機能（新規）
**機能概要**: 数量と単位の列分離表示による可読性向上

**現行フォーマット**:
```
数量
1000円
15%
50個
```

**修正後フォーマット**:
```
数量    |単
1000    |円
15      |%
50      |個
```

#### 2.2.2 RDLC レポート修正仕様
**対象ファイル**: OutputSeikyuReportS.rdlc

**修正内容**:
1. **列構造変更**
   - 数量列と単位列の分離
   - 列幅設定: 数量列3.0cm、単位列0.8cm
   - 縦線追加: Border.Styleプロパティ

2. **テキストボックス修正**
```xml
<!-- 修正前: 連結表示 -->
<Textbox Name="SURYO_TANI">
  <Value>=Format(Fields!SURYO.Value,"#,###") &amp; Fields!TANI.Value</Value>
</Textbox>

<!-- 修正後: 分離表示 -->
<!-- 数量列 -->
<Textbox Name="SURYO">
  <Value>=Format(Fields!SURYO.Value,"#,###")</Value>
  <Style>
    <Border>
      <Right>
        <Style>Solid</Style>
        <Width>1pt</Width>
      </Right>
    </Border>
  </Style>
</Textbox>

<!-- 単位列 -->
<Textbox Name="TANI">
  <Value>=Fields!TANI.Value</Value>
  <Style>
    <TextAlign>Center</TextAlign>
  </Style>
</Textbox>
```

3. **データソース連携**
   - T_SEIKYUテーブルの新規TANIフィールド使用
   - 既存単位定数（円、%）から新単位フィールドへの移行
   - NULL値・空値の適切な処理

#### 2.2.3 出力前検証機能
**機能概要**: 請求書出力前のデータ整合性チェック

**検証項目**:
- 単位フィールドの必須チェック
- 金額計算結果の妥当性確認
- 単価・数量の数値妥当性確認
