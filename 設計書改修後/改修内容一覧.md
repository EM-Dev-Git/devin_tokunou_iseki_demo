## 改修要件

### 1. 自動計算機能
**概要**: 単価×数量で金額を自動計算する機能を追加

### 2. 入力促進機能  
**概要**: 未入力項目の背景色変更による入力促進機能を追加

### 3. 金額フィールド保護
**概要**: 金額の手入力禁止（グレーアウト）機能を追加

### 4. 単位項目追加
**概要**: 請求書用の単位フィールドを新設

### 5. 単位入力必須化
**概要**: 単位未入力時のエラー表示機能を追加

## 技術仕様変更詳細

### データベース変更

#### T_SEIKYUテーブル変更
```sql
-- 新規フィールド追加
ALTER TABLE T_SEIKYU 
ADD TANI VARCHAR(10) NOT NULL DEFAULT 'その他';

-- 制約追加
ALTER TABLE T_SEIKYU 
ADD CONSTRAINT CK_T_SEIKYU_TANI 
CHECK (TANI IN ('個', '本', '台', '式', 'kg', 'm', '㎡', 'その他'));

-- インデックス追加
CREATE NONCLUSTERED INDEX IX_T_SEIKYU_TANI ON T_SEIKYU (TANI);
```
