### 1.3 改修概要（2025年6月6日版）

## 2. テーブル設計

### 2.1 T_SEIKYU テーブル（改修対象）

#### 2.1.1 テーブル概要
請求マスター情報を管理するテーブル

#### 2.1.2 フィールド定義

| 項目名 | 物理名 | データ型 | 桁数 | NULL | PK | FK | 初期値 | 備考 |
|--------|--------|----------|------|------|----|----|--------|------|
| 取引先コード | TORI_CD | VARCHAR | 10 | × | ○ | - | - | 既存項目 |
| 部品コード | BUHIN_CD | VARCHAR | 20 | × | ○ | - | - | 既存項目 |
| 単価 | TANKA | DECIMAL | 10,2 | × | - | - | 0 | 既存項目 |
| 数量 | SURYO | DECIMAL | 10,2 | × | - | - | 0 | 既存項目 |
| 金額 | KINGAKU | DECIMAL | 12,0 | × | - | - | 0 | 既存項目 |
| **単位** | **TANI** | **VARCHAR** | **10** | **×** | **-** | **-** | **その他** | **新規追加** |
| 備考 | BIKO | VARCHAR | 200 | ○ | - | - | - | 既存項目 |
| 作成日時 | CREATE_DATE | DATETIME | - | × | - | - | GETDATE() | 既存項目 |
| 更新日時 | UPDATE_DATE | DATETIME | ○ | - | - | - | - | 既存項目 |

#### 2.1.3 主キー
```sql
PRIMARY KEY (TORI_CD, BUHIN_CD)
```

#### 2.1.4 新規制約（TANI フィールド）
```sql

CHECK (TANI IN ('個', '本', '台', '式', 'kg', 'm', '㎡', 'その他'));
```

#### 2.1.5 新規インデックス
```sql

ON T_SEIKYU (TANI)
INCLUDE (TORI_CD, BUHIN_CD, KINGAKU);
```

### 3.2 データ移行スクリプト

#### 3.2.1 既存データの単位設定
```sql
-- 既存データに初期値設定
UPDATE T_SEIKYU 
SET TANI = 'その他' 
WHERE TANI IS NULL OR TANI = '';

-- 請求タイプ別の単位設定（必要に応じて）
UPDATE T_SEIKYU 
SET TANI = '円' 
WHERE SEIKYU_TYPE = 1 AND (TANI IS NULL OR TANI = 'その他');

UPDATE T_SEIKYU 
SET TANI = '%' 
WHERE SEIKYU_TYPE = 2 AND (TANI IS NULL OR TANI = 'その他');
```

#### 3.2.2 データ整合性チェック
```sql
-- 単位フィールドの整合性確認
SELECT TANI, COUNT(*) as COUNT
FROM T_SEIKYU 
GROUP BY TANI
ORDER BY COUNT DESC;

-- NULL値チェック
SELECT COUNT(*) as NULL_COUNT
FROM T_SEIKYU 
WHERE TANI IS NULL;

-- 制約違反チェック
SELECT *
FROM T_SEIKYU 
WHERE TANI NOT IN ('個', '本', '台', '式', 'kg', 'm', '㎡', 'その他');
```

## 4. データ辞書

### 4.1 TANI フィールド詳細

#### 4.1.1 値定義
| 値 | 説明 | 使用例 |
|----|------|--------|
| 個 | 個数単位 | 部品、製品の個数 |
| 本 | 本数単位 | パイプ、ケーブル等 |
| 台 | 台数単位 | 機械、装置等 |
| 式 | 一式単位 | セット商品、工事等 |
| kg | 重量単位 | 材料、原料等 |
| m | 長さ単位 | 配管、ケーブル等 |
| ㎡ | 面積単位 | 板材、シート等 |
| その他 | その他単位 | 上記以外の単位 |

#### 4.1.2 業務ルール
- 新規登録時は必須入力
- 既存データは「その他」で初期化
- 請求書出力時に表示される
- 変更履歴は UPDATE_DATE で管理
