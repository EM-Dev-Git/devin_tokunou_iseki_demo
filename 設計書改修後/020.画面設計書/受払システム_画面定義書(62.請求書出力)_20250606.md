# 受払システム 画面定義書 (62.請求書出力) 改修版_20250606

## 改修概要
本文書は、請求書出力画面に対する改修要件を反映した画面定義書です。

### 改修要件
1. **自動計算機能**: 単価×数量による金額自動計算の確認表示
2. **入力促進機能**: 出力前の未入力データ検証
3. **金額フィールド保護**: 自動計算された金額の表示
4. **単位項目追加**: 請求書への単位フィールド表示
5. **単位入力必須化**: 出力時の単位データ検証
6. **請求書フォーマット変更**: 数量と単位の列分離表示（縦線区切り、単位列0.8cm）

## データ検証機能（改修追加）

### 出力前検証

#### 検証項目
1. **単位フィールド必須チェック**
   - 対象データに単位未入力レコードがないか確認
   - 未入力データがある場合はエラーメッセージ表示

2. **自動計算値整合性チェック**
   - 単価×数量と金額フィールドの整合性確認
   - 不整合データがある場合は警告メッセージ表示

3. **データ完全性チェック**
   - 必須フィールドの入力確認
   - 異常値データの検出

#### 検証処理
```vb
Private Function ValidateOutputData() As Boolean
    Dim isValid As Boolean = True
    Dim errorMessages As New List(Of String)
    
    ' 単位未入力チェック
    Dim missingUnitCount As Integer = GetMissingUnitCount()
    If missingUnitCount > 0 Then
        errorMessages.Add($"単位が未入力のデータが{missingUnitCount}件あります。")
        isValid = False
    End If
    
    ' 金額計算整合性チェック
    Dim inconsistentAmountCount As Integer = GetInconsistentAmountCount()
    If inconsistentAmountCount > 0 Then
        errorMessages.Add($"金額計算に不整合があるデータが{inconsistentAmountCount}件あります。")
        isValid = False
    End If
    
    If Not isValid Then
        Dim message As String = String.Join(vbCrLf, errorMessages)
        MessageBox.Show(message, "データ検証エラー", MessageBoxButtons.OK, MessageBoxIcon.Warning)
    End If
    
    Return isValid
End Function
```

## イベント処理

### 1. 出力実行処理

#### 処理フロー
1. 出力条件の取得
2. データ検証の実行
3. 検証エラー時の処理停止
4. レポートデータの取得
5. RDLCレポートの生成
6. 出力形式に応じた処理実行

#### 実装例
```vb
Private Sub btnOutput_Click(sender As Object, e As EventArgs) Handles btnOutput.Click
    Try
        ' データ検証
        If Not ValidateOutputData() Then
            Return
        End If
        
        ' 出力条件取得
        Dim conditions As OutputConditions = GetOutputConditions()
        
        ' レポートデータ取得
        Dim reportData As DataTable = GetReportData(conditions)
        
        If reportData.Rows.Count = 0 Then
            MessageBox.Show("出力対象のデータがありません。", "情報", MessageBoxButtons.OK, MessageBoxIcon.Information)
            Return
        End If
        
        ' レポート生成・出力
        GenerateAndOutputReport(reportData)
        
    Catch ex As Exception
        MessageBox.Show($"出力処理でエラーが発生しました: {ex.Message}", "エラー", MessageBoxButtons.OK, MessageBoxIcon.Error)
    End Try
End Sub
```

## データソース定義

### SQL クエリ（改修版）
```sql
SELECT 
    s.SEIKYU_NO,
    s.TORIHIKISAKI_CD,
    s.TORIHIKISAKI_NAME,
    s.SEIKYU_DATE,
    s.HINMEI,
    s.TANKA,
    s.SURYO,
    s.TANI,  -- 新規追加フィールド
    s.KINGAKU,
    s.GOUKEI
FROM T_SEIKYU s
WHERE (@SEIKYU_NO IS NULL OR s.SEIKYU_NO = @SEIKYU_NO)
  AND (@TORIHIKISAKI_CD_FROM IS NULL OR s.TORIHIKISAKI_CD >= @TORIHIKISAKI_CD_FROM)
  AND (@TORIHIKISAKI_CD_TO IS NULL OR s.TORIHIKISAKI_CD <= @TORIHIKISAKI_CD_TO)
  AND (@SEIKYU_DATE_FROM IS NULL OR s.SEIKYU_DATE >= @SEIKYU_DATE_FROM)
  AND (@SEIKYU_DATE_TO IS NULL OR s.SEIKYU_DATE <= @SEIKYU_DATE_TO)
ORDER BY s.SEIKYU_NO, s.TORIHIKISAKI_CD
```

## テスト仕様

### 単体テスト項目

#### 1. フォーマット表示テスト
- **数量・単位列分離**: 正常な列分離表示の確認
- **縦線表示**: Border.Styleによる縦線の適切な表示
- **列幅確認**: 数量列3.0cm、単位列0.8cmの幅設定確認
- **文字表示**: 単位列0.8cm幅での各単位文字の表示確認

#### 2. データパターンテスト
- **通常データ**: 一般的な数量・単位組み合わせでの表示確認
- **特殊文字**: 単位に特殊文字が含まれる場合の表示確認
- **長い単位名**: 1文字制約を超える単位名の処理確認
- **NULL値処理**: 単位がNULLの場合の表示確認

#### 3. 出力形式テスト
- **プレビュー表示**: 画面プレビューでの列分離表示確認
- **PDF出力**: PDF形式での縦線・列分離の品質確認
- **直接印刷**: プリンター出力での表示品質確認

### 結合テスト項目

#### 1. データ連携テスト
- **請求マスター連携**: 登録画面で入力された単位データの正常出力確認
- **自動計算値連携**: 自動計算された金額の正常表示確認

#### 2. 画面遷移テスト
- **メニューからの呼び出し**: 正常な画面表示確認
- **プレビュー画面遷移**: プレビュー表示の正常動作確認
