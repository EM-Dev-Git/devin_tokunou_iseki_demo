# 受払システム 画面定義書 (17.請求マスター登録) 改修版_20250606

## 改修概要
本文書は、請求マスター登録画面に対する改修要件を反映した画面定義書です。

### 改修要件
1. **自動計算機能**: 単価×数量による金額自動計算
2. **入力促進機能**: 未入力フィールドの背景色変更
3. **金額フィールド保護**: 金額フィールドのグレーアウト
4. **単位項目追加**: 単位フィールドの追加
5. **単位入力必須化**: 単位フィールドの入力必須化

## 画面概要

### 画面ID
17

### 画面名
請求マスター登録

### 機能概要
請求に関するマスター情報の登録・更新・削除を行う画面

### 改修目的
請求処理の精度向上と入力ミス防止による会計処理ミスの根本的防止

## イベント処理

### 1. 自動計算機能

#### トリガーイベント
- 単価フィールドのLeaveイベント
- 数量フィールドのLeaveイベント
- 単価フィールドのTextChangedイベント（遅延処理）
- 数量フィールドのTextChangedイベント（遅延処理）

#### 処理仕様
```vb
Private Sub CalculateAmount()
    Try
        Dim tanka As Decimal = 0
        Dim suryo As Decimal = 0
        
        If Decimal.TryParse(txtTanka.Text, tanka) AndAlso _
           Decimal.TryParse(txtSuryo.Text, suryo) Then
            
            Dim kingaku As Decimal = Math.Round(tanka * suryo, 0)
            txtKingaku.Text = kingaku.ToString("#,##0")
        Else
            txtKingaku.Text = ""
        End If
    Catch ex As Exception
        MessageBox.Show("計算エラーが発生しました: " & ex.Message)
    End Try
End Sub
```

### 2. 入力検証機能

#### 背景色制御
```vb
Private Sub ValidateRequiredFields()
    ' 単価フィールド検証
    If String.IsNullOrEmpty(txtTanka.Text) OrElse txtTanka.Text = "0" Then
        txtTanka.BackColor = Color.FromArgb(255, 230, 230) ' #FFE6E6
    Else
        txtTanka.BackColor = SystemColors.Window
    End If
    
    ' 数量フィールド検証
    If String.IsNullOrEmpty(txtSuryo.Text) OrElse txtSuryo.Text = "0" Then
        txtSuryo.BackColor = Color.FromArgb(255, 230, 230) ' #FFE6E6
    Else
        txtSuryo.BackColor = SystemColors.Window
    End If
    
    ' 単位フィールド検証
    If String.IsNullOrEmpty(cmbTani.Text) Then
        cmbTani.BackColor = Color.FromArgb(255, 230, 230) ' #FFE6E6
    Else
        cmbTani.BackColor = SystemColors.Window
    End If
End Sub
```

### 3. 保存時検証

#### 必須項目チェック
```vb
Private Function ValidateInput() As Boolean
    Dim isValid As Boolean = True
    Dim errorMessage As String = ""
    
    ' 単位必須チェック
    If String.IsNullOrEmpty(cmbTani.Text) Then
        errorMessage += "単位を入力してください。" & vbCrLf
        isValid = False
    End If
    
    ' 単価必須チェック
    If String.IsNullOrEmpty(txtTanka.Text) OrElse txtTanka.Text = "0" Then
        errorMessage += "単価を入力してください。" & vbCrLf
        isValid = False
    End If
    
    ' 数量必須チェック
    If String.IsNullOrEmpty(txtSuryo.Text) OrElse txtSuryo.Text = "0" Then
        errorMessage += "数量を入力してください。" & vbCrLf
        isValid = False
    End If
    
    If Not isValid Then
        MessageBox.Show(errorMessage, "入力エラー", MessageBoxButtons.OK, MessageBoxIcon.Warning)
    End If
    
    Return isValid
End Function
```

## データベース連携

### INSERT処理
```sql
INSERT INTO T_SEIKYU (
    SEIKYU_NO,
    TORIHIKISAKI_CD,
    TORIHIKISAKI_NAME,
    SEIKYU_DATE,
    HINMEI,
    TANKA,
    SURYO,
    TANI,
    KINGAKU,
    SAKUSEI_DATE,
    SAKUSEI_USER
) VALUES (
    @SEIKYU_NO,
    @TORIHIKISAKI_CD,
    @TORIHIKISAKI_NAME,
    @SEIKYU_DATE,
    @HINMEI,
    @TANKA,
    @SURYO,
    @TANI,
    @KINGAKU,
    GETDATE(),
    @SAKUSEI_USER
)
```

### UPDATE処理
```sql
UPDATE T_SEIKYU SET
    TORIHIKISAKI_CD = @TORIHIKISAKI_CD,
    TORIHIKISAKI_NAME = @TORIHIKISAKI_NAME,
    SEIKYU_DATE = @SEIKYU_DATE,
```

## 運用仕様

### 操作手順
1. 請求番号の入力または自動採番
2. 取引先情報の選択・入力
3. 請求日の選択
4. 品名の入力
5. 単価の入力（背景色制御確認）
6. 数量の入力（背景色制御確認）
7. 単位の選択（必須項目）
8. 金額の自動計算確認
9. 登録ボタンクリック

### 注意事項
- 金額フィールドは手動入力不可
- 単位は必須選択項目
- 単価・数量未入力時は背景色で警告表示
- 自動計算は単価・数量入力後に実行
