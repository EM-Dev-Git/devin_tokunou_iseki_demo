## 4. 機能仕様

### 4.1 自動計算機能

#### 4.1.1 計算仕様
- **計算式**: 金額 = 単価 × 数量
- **計算タイミング**: 単価または数量フィールドの値変更時
- **小数点処理**: 四捨五入（円単位）
- **表示形式**: カンマ区切り（例：1,000）

#### 4.1.2 実装仕様
```vb
Private Sub CalculateAmount()
    Try
        If IsNumeric(txtTanka.Text) AndAlso IsNumeric(txtSuryo.Text) Then
            Dim tanka As Decimal = CDec(txtTanka.Text)
            Dim suryo As Decimal = CDec(txtSuryo.Text)
            Dim kingaku As Decimal = Math.Round(tanka * suryo, 0, MidpointRounding.AwayFromZero)
            txtKingaku.Text = kingaku.ToString("N0")
        Else
            txtKingaku.Text = "0"
        End If
    Catch ex As Exception
        txtKingaku.Text = "0"
        OutputLog.WriteLog("自動計算エラー: " & ex.Message)
    End Try
End Sub

Private Sub txtTanka_TextChanged(sender As Object, e As EventArgs) Handles txtTanka.TextChanged
    CalculateAmount()
    ValidateFields()
End Sub

Private Sub txtSuryo_TextChanged(sender As Object, e As EventArgs) Handles txtSuryo.TextChanged
    CalculateAmount()
    ValidateFields()
End Sub
```

### 4.2 入力促進機能

#### 4.2.1 背景色制御仕様
- **警告色**: #FFE6E6（薄い赤色）
- **正常色**: SystemColors.Window（白色）
- **検証タイミング**: フィールド離脱時（Leave イベント）
- **対象フィールド**: 単価、数量、単位

#### 4.2.2 実装仕様
```vb
Private Sub ValidateFields()
    ' 単価フィールドの検証
    If String.IsNullOrEmpty(txtTanka.Text) OrElse Not IsNumeric(txtTanka.Text) OrElse CDec(txtTanka.Text) <= 0 Then
        txtTanka.BackColor = Color.FromArgb(255, 230, 230)
    Else
        txtTanka.BackColor = SystemColors.Window
    End If
    
    ' 数量フィールドの検証
    If String.IsNullOrEmpty(txtSuryo.Text) OrElse Not IsNumeric(txtSuryo.Text) OrElse CDec(txtSuryo.Text) <= 0 Then
        txtSuryo.BackColor = Color.FromArgb(255, 230, 230)
    Else
        txtSuryo.BackColor = SystemColors.Window
    End If
    
    ' 単位フィールドの検証
    If String.IsNullOrEmpty(cmbTani.Text) Then
        cmbTani.BackColor = Color.FromArgb(255, 230, 230)
    Else
        cmbTani.BackColor = SystemColors.Window
    End If
End Sub
```

### 4.4 単位入力必須化機能

#### 4.4.1 保存時検証
```vb
Private Function ValidateForSave() As Boolean
    Dim isValid As Boolean = True
    Dim errorMessage As String = ""
    
    ' 単位必須チェック
    If String.IsNullOrEmpty(cmbTani.Text) Then
        errorMessage &= "単位を選択してください。" & vbCrLf
        cmbTani.BackColor = Color.FromArgb(255, 230, 230)
        isValid = False
    End If
    
    ' 単価必須チェック
    If String.IsNullOrEmpty(txtTanka.Text) OrElse Not IsNumeric(txtTanka.Text) OrElse CDec(txtTanka.Text) <= 0 Then
        errorMessage &= "単価を正しく入力してください。" & vbCrLf
        txtTanka.BackColor = Color.FromArgb(255, 230, 230)
        isValid = False
    End If
    
    ' 数量必須チェック
    If String.IsNullOrEmpty(txtSuryo.Text) OrElse Not IsNumeric(txtSuryo.Text) OrElse CDec(txtSuryo.Text) <= 0 Then
        errorMessage &= "数量を正しく入力してください。" & vbCrLf
        txtSuryo.BackColor = Color.FromArgb(255, 230, 230)
        isValid = False
    End If
    
    If Not isValid Then
        MessageBox.Show(errorMessage, "入力エラー", MessageBoxButtons.OK, MessageBoxIcon.Warning)
    End If
    
    Return isValid
End Function
```

## 6. データベース連携

### 6.1 T_SEIKYU テーブル更新
```vb
Private Function SaveSeikyuData() As Boolean
    Try
        Using conn As New SqlConnection(connectionString)
            conn.Open()
            Using cmd As New SqlCommand()
                cmd.Connection = conn
                cmd.CommandText = "INSERT INTO T_SEIKYU (TORI_CD, BUHIN_CD, TANKA, SURYO, KINGAKU, TANI, BIKO) " &
                                 "VALUES (@ToriCd, @BuhinCd, @Tanka, @Suryo, @Kingaku, @Tani, @Biko)"
                
                cmd.Parameters.AddWithValue("@ToriCd", txtToriCd.Text)
                cmd.Parameters.AddWithValue("@BuhinCd", txtBuhinCd.Text)
                cmd.Parameters.AddWithValue("@Tanka", CDec(txtTanka.Text))
                cmd.Parameters.AddWithValue("@Suryo", CDec(txtSuryo.Text))
                cmd.Parameters.AddWithValue("@Kingaku", CDec(txtKingaku.Text.Replace(",", "")))
                cmd.Parameters.AddWithValue("@Tani", cmbTani.Text)
                cmd.Parameters.AddWithValue("@Biko", txtBiko.Text)
                
                cmd.ExecuteNonQuery()
            End Using
        End Using
        Return True
    Catch ex As Exception
        MessageBox.Show("データ保存エラー: " & ex.Message, "エラー", MessageBoxButtons.OK, MessageBoxIcon.Error)
        Return False
    End Try
End Function
```
