# 受払システム 画面定義書 (62.請求書出力) 改修版

## 改修概要
本文書は、井関物流受払管理システムの請求書出力画面に対する改修要件を反映した設計書です。

### 改修要件
1. **単位項目表示**: 請求書への単位フィールド表示追加
2. **出力前検証**: 必須項目未入力時の出力防止機能
3. **金額表示改善**: 自動計算された金額の正確な表示
4. **エラー表示**: 不完全なデータに対する警告表示

## 画面仕様

### 画面ID
**62.請求書出力**

### 画面名
**請求書出力画面**

### 機能概要
登録された請求データを基に請求書を出力する画面です。改修により、単位項目の表示と出力前検証機能が追加されます。

## 改修仕様詳細

### 1. 単位項目表示
**機能**: 請求書への単位フィールド表示追加

**実装仕様**:
- 明細部に「単位」列を追加
- T_SEIKYUテーブルのTANIフィールドから取得
- 列幅: 40px
- 配置: 数量列の右隣

### 2. 出力前検証
**機能**: 必須項目未入力時の出力防止機能

**実装仕様**:
- 出力ボタン押下時に検証処理を実行
- 以下の項目をチェック:
  - 単価が0または未入力
  - 数量が0または未入力
  - **単位が未選択**
  - 金額が0または未計算

**検証エラー時の動作**:
- エラーダイアログを表示
- 該当データの詳細をリスト表示
- 出力処理を中断

### 3. 金額表示改善
**機能**: 自動計算された金額の正確な表示

**実装仕様**:
- 金額の表示形式: カンマ区切り（例: 1,000）
- 小数点以下の処理: 四捨五入後2桁表示
- 合計金額の自動計算と表示

### 4. エラー表示
**機能**: 不完全なデータに対する警告表示

**実装仕様**:
- 出力対象データの事前チェック
- 問題のあるデータをハイライト表示
- エラー内容の詳細表示

## 出力前検証ルール

### 必須項目チェック
1. 請求番号の存在確認
2. 取引先情報の完全性確認
3. 明細データの完全性確認
   - 品名の入力確認
   - 単価 > 0の確認
   - 数量 > 0の確認
   - **単位の選択確認**
   - 金額の計算確認

### データ整合性チェック
1. 金額 = 単価 × 数量の確認
2. 合計金額の計算確認
3. 日付の妥当性確認

## エラーメッセージ一覧

| エラーコード | メッセージ | 表示条件 |
|-------------|-----------|----------|
| E101 | 「出力対象のデータが見つかりません。」 | 検索結果0件 |
| E102 | 「単価が未入力または0の明細があります。」 | 単価不正 |
| E103 | 「数量が未入力または0の明細があります。」 | 数量不正 |
| **E104** | **「単位が未選択の明細があります。」** | **単位未選択** |
| E105 | 「金額が正しく計算されていない明細があります。」 | 計算エラー |
| E106 | 「出力処理中にエラーが発生しました。」 | システムエラー |

## 処理フロー

### 画面表示時
1. 検索条件の初期化
2. 前回検索条件の復元（可能な場合）
3. 出力形式の初期設定（PDF）

### 検索実行時
1. 検索条件の妥当性チェック
2. データベース検索実行
3. 検索結果の一覧表示
4. 各レコードの状態判定（正常/エラー）

### 出力実行時
1. 選択データの検証実行
2. エラーデータの確認・表示
3. 正常データのみ出力処理実行
4. 出力完了メッセージ表示

## データベース連携

### 参照テーブル
- **T_SEIKYU**（請求テーブル）
- **M_TORIHIKISAKI**（取引先マスター）

### 取得項目
```sql
SELECT 
    s.SEIKYU_NO,
    s.TORIHIKISAKI_CD,
    t.TORIHIKISAKI_NAME,
    s.SEIKYU_DATE,
    s.HINMEI,
    s.TANKA,
    s.SURYO,
    s.TANI,        -- 新規追加
    s.KINGAKU,
    s.GOUKEI
FROM T_SEIKYU s
LEFT JOIN M_TORIHIKISAKI t ON s.TORIHIKISAKI_CD = t.TORIHIKISAKI_CD
WHERE s.SEIKYU_DATE BETWEEN ? AND ?
  AND (? IS NULL OR s.TORIHIKISAKI_CD = ?)
ORDER BY s.SEIKYU_NO
```

## 帳票仕様
