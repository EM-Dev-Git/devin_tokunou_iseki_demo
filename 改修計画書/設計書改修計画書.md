# 井関物流受払管理システム 設計書改修計画書

## 1. 改修概要

### 1.1 改修目的
生産受払システムにおける請求処理の精度向上と業務効率化を目的とした機能追加・改修を実施する。

### 1.2 改修背景
- 会計処理でのエラー発生（出荷運賃請求関連）
- 手動計算による入力ミスの発生
- 必須項目の入力漏れによる請求書発行エラー
- 業務担当者の作業負荷軽減の必要性

## 2. 改修要件詳細

### 2.1 要件①：自動計算機能の追加
**概要**: 単価、数量入力後、金額が自動計算される機能を追加する

**詳細仕様**:
- 単価フィールドまたは数量フィールドの値変更時に金額を自動計算
- 計算式: 金額 = 単価 × 数量
- 小数点以下の処理: 四捨五入（円単位）
- 計算結果の即座反映

**対象設計書**:
- 受払システム_画面定義書(17.請求マスター登録).xlsx
- 受払システム_画面定義書(62.請求書出力).xlsx
- 受払管理システム_DB論理設計書.xlsx

**実装対象**:
- 請求マスター登録フォーム（VB.NET）
- 請求書出力フォーム（VB.NET）
- T_SEIKYU テーブル関連処理

### 2.2 要件②：入力促進機能の追加
**概要**: 単価、数量いずれか未入力の場合、入力を促す背景反転色付けする機能を追加する

**詳細仕様**:
- 単価フィールドが未入力（空白またはゼロ）の場合、背景色を警告色に変更
- 数量フィールドが未入力（空白またはゼロ）の場合、背景色を警告色に変更
- 入力完了時に背景色を通常色に戻す
- 警告色: 薄い赤色（#FFE6E6）または黄色（#FFFFCC）

**対象設計書**:
- 受払システム_画面定義書(17.請求マスター登録).xlsx
- 井関物流 受払管理システム基本設計書.docx

**実装対象**:
- 請求マスター登録フォームのUI制御
- フィールド検証ロジック

### 2.3 要件③：金額フィールド保護機能
**概要**: 金額は手入力ができないようグレーアウトにする

**詳細仕様**:
- 金額フィールドを読み取り専用に設定
- 背景色をグレー（#F0F0F0）に変更
- フォーカス移動時にスキップ
- 自動計算結果のみ表示

**対象設計書**:
- 受払システム_画面定義書(17.請求マスター登録).xlsx
- 受払システム_画面定義書(62.請求書出力).xlsx

**実装対象**:
- 請求関連フォームのUI制御
- TextBoxコントロールのプロパティ設定

### 2.4 要件④：単位項目の追加
**概要**: 請求書記載の数量の単位については、「単位」単独の項目を追加する

**詳細仕様**:
- 新規フィールド「単位」を請求マスターに追加
- データ型: VARCHAR(10)
- 初期値: 空白
- 選択肢: 個、台、セット、式、その他（コンボボックス形式）

**対象設計書**:
- 受払管理システム_DB論理設計書.xlsx
- 受払システム_画面定義書(17.請求マスター登録).xlsx
- 受払システム_画面定義書(62.請求書出力).xlsx

**実装対象**:
- T_SEIKYU テーブルスキーマ変更
- 請求マスター登録フォーム
- 請求書出力フォーム
- データベースアクセス層（DitDataAccess）

### 2.5 要件⑤：単位入力必須化
**概要**: 追加項目の単位は入力必須項目とし、未入力の場合背景色付けエラーにする

**詳細仕様**:
- 単位フィールドが未入力の場合、背景色を赤色（#FFE6E6）に変更
- 保存時に単位未入力チェックを実施
- エラーメッセージ表示: 「単位を入力してください」
- 入力完了時に背景色を通常色に戻す

**対象設計書**:
- 受払システム_画面定義書(17.請求マスター登録).xlsx
- 井関物流 受払管理システム基本設計書.docx

**実装対象**:
- 請求マスター登録フォームの検証ロジック
- エラーハンドリング機能

## 4. 実装方針

### 4.1 VB.NET アプリケーション修正

#### 4.1.1 請求マスター登録フォーム
```vb
' 自動計算処理
Private Sub CalculateAmount()
    If IsNumeric(txtTanka.Text) AndAlso IsNumeric(txtSuryo.Text) Then
        txtKingaku.Text = (CDec(txtTanka.Text) * CDec(txtSuryo.Text)).ToString("N0")
    End If
End Sub

' 背景色制御
Private Sub ValidateFields()
    ' 単価チェック
    If String.IsNullOrEmpty(txtTanka.Text) OrElse CDec(txtTanka.Text) = 0 Then
        txtTanka.BackColor = Color.FromArgb(255, 230, 230)
    Else
        txtTanka.BackColor = SystemColors.Window
    End If
    
    ' 数量チェック
    If String.IsNullOrEmpty(txtSuryo.Text) OrElse CDec(txtSuryo.Text) = 0 Then
        txtSuryo.BackColor = Color.FromArgb(255, 230, 230)
    Else
        txtSuryo.BackColor = SystemColors.Window
    End If
    
    ' 単位チェック
    If String.IsNullOrEmpty(cmbTani.Text) Then
        cmbTani.BackColor = Color.FromArgb(255, 230, 230)
    Else
        cmbTani.BackColor = SystemColors.Window
    End If
End Sub
```

#### 4.1.2 データベースアクセス層
```vb
' T_SEIKYU テーブル更新SQL
Private Const SQL_UPDATE_SEIKYU As String = _
```
